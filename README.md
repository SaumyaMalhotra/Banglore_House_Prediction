# Banglore_House_Prediction
Machine learning-based House Price Prediction App built using Python, scikit-learn, pandas, NumPy, and Streamlit. Predicts property prices based on location, square feet, BHK, bathrooms, and balconies. Includes data preprocessing, feature engineering, model optimization, and interactive web deployment.

# House Price Prediction App

A machine learning-based House Price Prediction App built using Python, scikit-learn, pandas, NumPy, and Streamlit. The application predicts Bangalore house prices based on factors like location, total square feet, BHK, bathrooms, and balconies.

## Features

* Real-time house price prediction
* Interactive Streamlit web interface
* Data preprocessing and feature engineering
* Multiple ML models with GridSearchCV optimization
* Clean UI with responsive design

## Tech Stack

* Python
* pandas
* NumPy
* scikit-learn
* Streamlit

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
